\# Effe Website



WordPress-Website für den Haus- und Hofservice Effe.



\## Produktion



Die produktive Website läuft bei IONOS auf WordPress.



\## Repository



Dieses Repository enthält die von uns bearbeiteten bzw. entwicklungsrelevanten Dateien der Website.



Aktuell:



\- `theme/` – verwendetes WordPress-Theme bzw. Theme-Dateien

\- `AGENTS.md` – Arbeitsanweisungen für Coding Agents



Die WordPress-Datenbank, Uploads, Zugangsdaten und WordPress-Core-Dateien gehören nicht in dieses Repository.
